# Music for the earn corner (음악 감상)

Put audio files (mp3 / ogg / m4a / wav) in this folder and list them in list.json:

```json
["song1.mp3", { "file": "song2.mp3", "title": "My Song" }]
```

A random 30-second section of a random track plays when a player uses the music corner.
With an empty list a synthesized BGM plays instead.
